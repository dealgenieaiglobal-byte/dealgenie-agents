How it works

1) Slug routing

/agent/<slug> routes to a single HTML template via a small redirect rule. JavaScript reads the slug from the URL and loads the agent data.

2) Data source

Demo uses /data/agents.json (simple). Later you can swap to Airtable by adding an API proxy (Cloudflare Worker / Netlify Function) for secure keys.

3) Botpress embed

Put your Botpress scripts in /assets/config.js and set enabled: true. Each agent can have a different bot config if needed.
